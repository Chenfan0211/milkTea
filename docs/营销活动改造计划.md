# 营销活动菜单改造执行计划

## 目标
运营后台「营销中心」完整实现优惠券、储值套餐、积分兑换三大功能，字段与小程序端 `user-h5/data/mock.js` 对齐，可配置。

## 已确认决策
- 优惠券 `amount` 统一改为「元」（方案A），列表不再用 `renderMoney`（分÷100）。
- 储值套餐赠送券 = 从「已启用优惠券列表」选券 + 设赠送张数。
- 优惠券需配图；积分商品可编辑 image/stock/badge/limitText/description。
- 新增「积分规则」菜单（获取规则 + 签到规则）。

## 改动清单

### 1. 通用能力（types.ts + AdminListPage.vue）
- FormField.type 增加 `'date'`、`'textarea'`。
- AdminListPage.renderField 增加 date（NDatePicker，YYYY-MM-DD）和 textarea（NInput type=textarea）分支。
- 新增 renderYuan（直接显示元，不做 ÷100）辅助，或优惠券列直接 render 原值。

### 2. 数据层（admin/index.ts）
- coupons seed：amount 改元（300→3、500→5、0→0），补 image/brand/scenes/source/description/applicableStoreIds/applicableProductIds。
- storedValuePackages seed：coupons 每项补 id（关联 coupons.id）。
- pointsProducts seed：补 image/stock/badge/limitText/description。
- 新增 signInRule seed（daily/streakDays/streakReward）。
- migrate() 补新字段兜底。
- 暴露 signInRule computed。

### 3. 优惠券管理（coupon/index.vue）
- 列：加券面图/品牌/使用场景/来源；amount 直接显示元。
- 表单：加 image/brand/scenes/source/description/validityPeriod/usageTime/applicableStoreIds/applicableProductIds。
- onSubmit 处理 amount 元存储。

### 4. 储值套餐（stored/index.vue）
- 表单：amount（元）+ 赠送券编辑器（选 enabled 券 + 张数）。
- 新建 GiftCouponsEditor.vue 组件。

### 5. 积分商城（points/index.vue）
- 列：加图片/库存/角标/限购说明。
- 表单：加 image/stock/badge/limitText/description。

### 6. 积分规则（新页面 points-rule/index.vue）
- 获取规则列表（增删改）+ 签到规则编辑。
- 路由注册 + seed。
