# 小程序商城实施记录

> 实施日期：2026-10-25  
> 范围：商城商品、SKU 库存、购物车、地址、订单履约、支付、退款、分佣、订阅消息与运营后台。

## 一、已实现能力

- “我的”页恢复“收货地址”并新增“线上商城”入口，商城位于 `packageMall` 分包。
- 商城支持一级分类、单维多 SKU、SKU 独立价格与库存、售罄标记及后端稳定沉底。
- 购物车按登录用户隔离保存在本地；进入购物车和结算时由后端重新校验上架状态、价格与库存。
- 商城结算固定使用 SKU 售价，不叠加会员价、储值立减、优惠券或积分抵扣；全场包邮。
- 支持微信支付和现有储值余额支付，不支持组合支付。
- 用户可维护收货地址（最多 20 条、默认地址、省市县与详细地址），下单时保存地址快照。
- 商城订单状态为 `CREATED → PAID → SHIPPED → COMPLETED`，取消为 `CANCELED`；客户端下单带 `clientRequestId`，同一用户重复提交返回同一订单，不重复预占库存。
- 下单锁定库存 15 分钟；支付成功后扣减库存；超时/未支付取消释放库存；发货前退款成功后回补库存。订单超时关单与库存释放同一业务重试链路；未支付取消遇到远程已扣减时会原额补回，避免永久少库存。
- 后台填写快递公司和快递单号后变为待收货，并设置发货后 15 天自动完成。
- 用户确认收货与定时自动完成共用同一状态机，完成时幂等发布五方分账、积分、成长值和邀请首单奖励事件。
- 商城订单进入主订单页“商城订单”分类，同时商城分包提供独立订单列表与详情。
- 发货通知通过微信订阅消息异步发送，模板未配置时静默跳过，不影响订单状态。

迁移文件：`server/src/main/resources/db/migration/V86__mall_commerce.sql`。

## 三、分佣口径

- 商城商品由运营指定归属门店，可选归属渠道，SKU 必须指定供应商。
- 下单时快照完整分账规则参数、成本价、平台提成和供应商；订单完成时按不可变快照发布现有五方分账事件。
- 积分、会员成长值和邀请首单奖励只在订单完成后累计，发货前退款不产生正向权益。
- 商城订单与门店订单共用 `orders` 主键空间，因此分账快照可直接按订单 ID 幂等。

## 四、部署配置

- `WX_MALL_SHIPPED_TEMPLATE_ID`：微信“商城发货通知”模板 ID，trade-service 与小程序 `utils/subscribe-message.js` 使用的模板必须一致。
- `mall_shipped_template_id`：`app_config` 中供小程序申请订阅授权的公开模板 ID。
- `MALL_AUTO_COMPLETE_ENABLED`、`MALL_AUTO_COMPLETE_BATCH_SIZE`、`MALL_AUTO_COMPLETE_CRON`：15 天自动完成任务配置。
- 商品上架前需确保归属门店、供应商和当前全局分账规则有效。
