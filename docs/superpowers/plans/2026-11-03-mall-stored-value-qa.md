## 接口与断言

- 复用商城报价/建单、`POST /api/v1/app/orders/{orderNo}/pay-by-balance`、取消、发货、收货和售后审核接口；默认不新增公开 API 或迁移。
- 扣款幂等号 `PAY:<orderNo>`；整单退款 `REFUND:<orderNo>`；部分售后退款 `REFUND:<orderNo>:AS:<afterSaleId>`。同一业务重试不重复资金动作，不同售后可独立退回。
- 每步使用分为单位对账：`当前余额 = 初始余额 - 本轮成功扣款 + 本轮成功退款`，其他账户活动单独列示。全退后本轮净变化为 0；累计退款不超过原实付。
- 支付成功后预占归零、库存扣一次；整单和分次回补累计不超过原扣减。完成后结算与冲正累计保持一致；重复请求不重复发事件。
- 退款到账与本地状态必须共同成立才判成功；部分失败保持可对账、可按原资金业务号恢复，不能伪置成功或再次入账。
