## 一、核心结论（重要）

本项目存在**两套规范约束**，二者存在张力：

1. **`docs/design-system.md`**：设计规范，要求字号仅 7 档、间距仅 8 档、颜色必须用 token。
2. **`user-h5/scripts/*.test.mjs` 验收测试**：硬性验收，大量固化了「参考图精确还原」的像素值（如 `18rpx` 字号、`14rpx/15rpx/9rpx/6rpx` 间距、`#2D2D2D`/`#FFFFFF` 字面量等），**这些值故意偏离 token 档位规范**。

**处理原则**：测试固化值优先（它们是验收标准），仅对「测试未固化」的违规项进行 token 归并。
