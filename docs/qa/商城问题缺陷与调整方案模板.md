## 二、分级判定细则

| 级别 | 判定标准                                     | 示例                                             |
| ---- | -------------------------------------------- | ------------------------------------------------ |
| P0   | 资金错账、库存不可逆错误、越权访问、数据损坏 | 退款重复入账；佣金算错；普通用户可调后台接口     |
| P1   | 核心链路阻断或可绕过校验                     | 无法下单；结算金额与实付不一致；库存为负仍可下单 |
| P2   | 非核心功能异常                               | 筛选偶发失效；分页跳页异常                       |
| P3   | 文案、样式、体验                             | 状态文案不统一；间距偏差                         |

## 三、调整方案编写要求

1. 先复现再修复：无稳定复现步骤的问题先补证据。
2. 先写回归测试：阻断类问题必须有失败用例再改代码。
3. 最小改动：只改与问题直接相关的代码。
4. 金额只信服务端：任何前端金额参与写库的方案一律否决。
5. 幂等优先：库存、退款、分账修复必须说明幂等键与重复执行结果。
6. 可回滚：说明是否需要迁移、是否需要数据修补、失败如何回退。
7. 回归齐全：覆盖原链路、相邻错误分支与全量门禁。
