# 先浏览后登录整改与微信开发者工具验收

日期：2026-11-02。

## 整改结果

- 首页选择堂食、自取直接进入公开菜单，不再要求先登录。
- 请求层默认不因后台刷新失败弹出登录提示；错误继续返回调用方，明确的用户操作可通过 `promptLogin: true` 请求提示。
- 失效请求只清理与其 token 对应的会话；网络重试失败保留有效会话，迟到的旧响应不会删除新登录态。
- 登录弹层无需勾选协议也可跳过；弹层和独立授权页的原生手机号按钮在未勾选协议时真正禁用。
- 按钮明确显示“手机号授权登录”，协议默认不勾选。取消、拒绝授权时清理待执行动作并返回原浏览位置。
- 头像昵称仍由用户在个人资料页自行设置，本次未增加任何头像昵称授权。

- 本次启动场景验证的是清登录态后的启动页入口；不是新微信账号在真机上首次启动。
- 手机号拒绝使用开发者工具原生事件回调模拟，未在真机验证手机号授权成功、真实注册或绑定。
- 选店和规格层部分由 Skyline 页面的原有事件处理器驱动；未将它们记为真实手指点击验收。
- 未发起真实下单、支付、充值，也未上传小程序或提交审核。
- 仍需使用最终提审版本在真机完成首次进入、主动授权登录及拒绝授权的复核；平台审核结果不在本次本地验收范围内。
