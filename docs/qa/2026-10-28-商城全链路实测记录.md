## 二、本次发现并修复的缺陷

### BUG-20261028-01 分销佣金未透传到订单服务（P0）

- 现象：非团长报价 `unitPrice=1000`，应为 1100；订单 `distribution_commission` 为 0
- 根因：`MallProductQueryService.toInternalView` 未映射 `distributionCommission`
- 影响：所有非团长订单少收佣金，团长分佣为 0
- 修复：补映射 + 单测断言

### BUG-20261028-02 库存流水缺 `biz_type` 导致支付必失败（P0）

- 现象：支付回调报「订单尚未预占库存」，`mall_stock_log.biz_type` 为 NULL
- 根因：`MallInventoryService.writeLog` 接收 `bizType` 但未写入实体
- 影响：所有商城订单支付无法完成（阻断）
- 修复：补 `log.setBizType(bizType)` + 单测断言；线上历史 1 条记录已修正

### BUG-20261028-03 结算记录未写 `original_amount`（P1）

- 现象：`settlement_record.original_amount` 全为 NULL
- 根因：`LedgerService.recordSettled/recordSettledPart` 未设置原额
- 影响：累计冲正依赖运行时兜底，对账口径与 V90 设计不一致
- 修复：写入 `originalAmount` 与 `refundedAmount=0` + 单测断言

### BUG-20261028-04 团长身份查询接口契约不匹配（P0）

- 现象：`leaderBuyer` 恒为 false，团长仍被加收佣金；trade 日志 `404`
- 根因：server 为 `GET /internal/user-leader?userId=`，trade 用 `/internal/user-leader/{userId}`
- 影响：分销佣金全部错分给平台，团长价格口径失效
- 修复：客户端改查询参数 + 契约单测

### BUG-20261028-05 已绑定门店的用户无法设为团长（P1）

- 现象：设团长返回 500 `Duplicate entry for uk_biz_subject_bound_user`
- 根因：LEADER 主体写 `bound_user_id`，与门店主体唯一键冲突，违背“可共存”设计
- 影响：绝大多数经营角色用户无法成为团长
- 修复：LEADER 主体不写该列，用户关联只走 `user_role_grant`；解绑不再清空其他角色绑定 + 3 条契约测试

### 附：网关路由缺失（P0，详见 BUG-20261027-01）

生产外部网关配置缺 `/api/v1/app/mall/checkout/quote`、`/api/v1/admin/mall/**`、`/api/v1/app/mall/after-sales`、`/api/v1/app/addresses` 等路由，导致 404/“资源不存在”。已逐条补齐并加 `MallRouteContractTest`。

> 说明：根因是**生产使用宿主机外部 `application-prod.yml`，与仓库默认配置不同步**。建议后续把外部配置纳入版本管理或启动时校验，避免再次漂移。
