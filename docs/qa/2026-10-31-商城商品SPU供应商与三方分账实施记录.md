# 商城商品 SPU 供应商与三方分账实施记录（2026-10-31）

## 调整范围

- 商城商品统一面向全部门店销售，后台移除归属门店、归属渠道、分账规则和排序展示。
- 供应商提升为 SPU 唯一供应商，所有 SKU 自动继承。
- 商品主图、SKU 图片改用系统文件上传，不再展示图片地址。
- SKU 编辑区改为紧凑表格，全部金额按元展示和录入，接口继续按分存储。
- 新商城订单按“平台 + 供应商 + 团长”分账，门店、渠道、投资人为 0。

## 数据迁移

- 使用 `V98__mall_product_supplier.sql`，避开工作区已占用的 V97 迁移号。
- 迁移前检查同一商品是否存在多个 SKU 供应商；存在冲突时通过临时表 `CHECK` 强制失败。
- 单一供应商商品自动回填到 `mall_product.supplier_subject_id`。
- `orders` 新增 `leader_subject_id`、`leader_user_id`，并允许商城订单 `store_subject_id` 为空。

## 兼容策略

- `mall_product` 旧门店、渠道、分账列暂不删除，但不再由后台接口维护或返回。
- `mall_sku.supplier_subject_id` 保留为非空兼容列，保存时统一写入 SPU 供应商。
- 已存在的历史订单及已完成分账快照不重新计算。
