# 商城全流程上线验收清单

> 适用范围：商城商品 → 上架 → 小程序浏览/加购 → 结算支付 → 发货收货 → 退款售后 → 运营后台。
> 原则：mock 支付只证明页面与状态机可走通，**不得替代真实微信支付/退款验收**。

## 0. 前置条件

- [ ] 数据库已执行 V86–V91 全部迁移，`flyway_schema_history` 无失败记录。
- [ ] `app.pay.channel=wxpay`，微信支付商户号、证书、API v3 密钥、回调域名配置完整。
- [ ] `WXPAY_REFUND_NOTIFY_URL` 可公网访问且验签通过。
- [ ] 商城归属门店、供应商、分账规则均有效；至少一个分类和一个含 SKU 的商品可上架。
- [ ] 小程序 `USE_MOCK=false` 且 `BASE_URL` 指向被测环境。

## 1. 商品配置与上架

- [ ] 后台新建分类，停用分类不出现在小程序分类列表。
- [ ] 新建商品草稿，保存多个 SKU（编码唯一、规格唯一、售价/划线价/成本/佣金非负）。
- [ ] 未配置归属门店、供应商或分账规则时，上架被拒绝并展示明确原因。
- [ ] 上架成功后小程序首页出现商品，售价按服务端成交价展示。
- [ ] 售罄商品仍展示但沉底，详情页不可购买。
- [ ] 已有库存流水/历史订单的商品，删除按钮不可用或被后端拒绝，只能下架。

## 2. 浏览、购物车与结算

- [ ] 商品详情切换 SKU 时价格与可用库存同步刷新。
- [ ] 加购后购物车金额、数量与商品详情一致。
- [ ] 购物车停留期间后台改价/下架/减库存，进入结算时提示价格或库存变化，不静默下单。
- [ ] 非团长与团长分别进入结算，页面“应付”与服务端 `payableAmount` 一致。
- [ ] 下单后若服务端实付与结算确认金额不一致，前端阻止直接支付并提示刷新。

## 3. 支付与库存

- [ ] 微信支付：下单 → 拉起收银台 → 支付成功 → 订单变 `PAID` → 库存由预占转扣减。
- [ ] 余额支付：余额充足时支付成功；余额不足时订单保持待支付且不扣库存。
- [ ] 支付成功但库存扣减失败时，订单不得静默显示成功，必须进入可补偿/对账路径。
- [ ] 15 分钟未支付自动关单并释放预占库存；用户主动取消同样释放。
- [ ] 同一 `clientRequestId` 重复提交只生成一个订单、只预占一次库存。

## 4. 发货与收货

- [ ] 后台仅 `PAID` 且非退款处理中的订单可发货，必须填写快递公司与单号。
- [ ] 发货后订单变 `SHIPPED`，小程序显示物流信息与 15 天自动完成倒计时。
- [ ] 用户确认收货后订单变 `COMPLETED`，只生成一次分账、积分与成长值事件。
- [ ] 15 天到期自动完成与手动确认收货互斥，不重复结算。

## 5. 退款售后

- [ ] 发货前 `PAID` 订单走整单退款，成功后订单变 `REFUNDED`，库存回补一次。
- [ ] 已发货/已完成订单可申请部分退货，退款金额由服务端按明细单价计算。
- [ ] 有处理中售后时，订单详情不再展示“申请售后”，订单列表展示“售后处理中”并可查看记录。
- [ ] 售后审核通过后生成退款单并进入 `REFUNDING`；微信退款成功后售后变 `SUCCESS`。
- [ ] 部分退款保持订单 `SHIPPED/COMPLETED`，只有全部数量退完才变 `REFUNDED`。
- [ ] 退款失败售后变 `FAILED`，订单保持原业务状态，可由后台重试且不重复回补库存。
- [ ] 同一订单多次部分退款，结算冲正累计不超扣、不重复扣。

## 6. 后台与菜单

- [ ] 动态菜单包含“商城分类 / 商城商品 / 商城订单 / 售后审核”。
- [ ] 商城商品列表可按名称/编码、分类、状态筛选，分页正确。
- [ ] 库存调整弹窗同时展示总库存、锁定库存与调整后可用库存。
- [ ] 售后审核页可按状态与订单号/售后单号筛选，详情展示退款单号、失败原因。
- [ ] 无权限角色不可访问商城与售后接口。

## 7. 对账与可观测性

- [ ] `mall_stock_log` 中 `ORDER` 与 `AFTER_SALE` 业务号可区分，同一业务号不重复入账。
- [ ] `settlement_record.original_amount/refunded_amount` 与多次退款累计冲正一致。
- [ ] 支付、库存扣减、发货、退款、售后审核均有可检索日志。
- [ ] 对账异常可查询到订单号、退款单号、主体与金额缺口。

## 8. 验收结论

- [ ] mock 环境验证记录（仅证明页面/状态机）
- [ ] 真实微信支付验证记录（订单号、交易号、金额、时间）
- [ ] 真实微信退款验证记录（退款单号、金额、时间）
- [ ] 未通过项已登记负责人与修复计划，**未完成真实支付/退款验证不得标记资金验收完成**。
